FileInfra is a Dufs-based, lightweight cross-platform file distribution GUI optimized for air-gapped LANs and restricted industrial environments. Install it on ONE device, tap start, and anyone on the same network can upload and download files instantly via browser — no app needed on the other side.

Pick a folder or a single file, tap start, and share.

Features:
• One-tap file sharing via HTTP
• Upload files from any browser
• QR code for easy access
• File transfer log
• Customizable permissions (read-only, upload, full)
• Multi-language support (English, 简体中文, 繁體中文)
• Material 3 design with 6 color themes
• Desktop drag & drop support
• System tray integration
• Shared LAN clipboard and offline QR tools page
• Android notification and Quick Settings start/stop controls

Files and shared clipboard text go directly to the peers you connect to. No analytics or cloud relay is used. HTTP content is unencrypted, and the separate tools page is not protected by the file-server password. Notification Send opens FileInfra before reading the clipboard once; after a tile-only start, open the app to initialize tools.
